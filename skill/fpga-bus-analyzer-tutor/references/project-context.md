# 项目约定与关键边界

本文件保存学习计划的设计目标及为实现目标所需的解释约定。它们不代表硬件已连接、模块已实现或指标已实测。

阶段七当前已实现且现场通过的接口，以及接入下一阶段时的边界，见 [阶段七已验证接口与移植](stage7-debug-interfaces.md)。该参考与本文件的规划目标分开；实际完成状态仍以学习记录和对应现场证据为准。

## 数据与控制路径

```text
外部SCL/SDA -> 两级同步 -> 按sample_ce取样 -> 4位样点 -> 环形缓存
                            |                         |
                            +-> 边沿/I2C解析 -> 触发   |
手动一拍事件 / SCL低超时 -----------------> 捕获控制器 |
                                                      v
                                 冻结缓存+元数据 -> 组帧 -> UART -> 电脑
V2：复制第二个I2C解析器 -> 关联规则 -> 捕获控制器
```

`capture_ctrl` 管布防、首次触发、后触发采样、冻结、上传、重新布防。缓存和协议解析共享样点时间基准；事件经过寄存器时，编号要与造成事件的样点一起传递或明确补偿，不能用迟到一拍的当前编号替代。

建议目录沿用计划的 `rtl/common`、`rtl/capture`、`rtl/protocol`、`rtl/transport`、`rtl/top`、`sim`、`pc`、`constr`、`mcu`、`data`、`report`。已有结构能工作就按其结构增量修改，不为满足目录模板重组工程。

## 参数与单位

| 项目 | 基础目标 | 说明 |
|---|---|---|
| FPGA | 升腾Pro XC7A100T | 是计划平台；封装/速度等级/板卡版本查实际资料 |
| 系统时钟 | 50 MHz | 20 ns一拍；全部核心逻辑用此时钟 |
| 采样使能 | 每5拍一次 | 10 MSa/s；100 ns一个样点；不是新增时钟 |
| 通道 | 4路 | V1用CH0=SCL_A、CH1=SDA_A；未用位值明确；V2接SCL_B/SDA_B |
| 正式缓存 | 4 bit × 32768 | 逻辑数据容量131072 bit=16 KiB，实际BRAM分配看配置与报告 |
| 采集窗口 | 32768 / 10000000 s | 约3.2768 ms；默认前后各约1.6384 ms |
| I2C | 100 kHz、7位地址、单控制器 | 主线不先扩到400kHz、多控制器、10位地址 |
| SCL低阈值 | 演示0.5 ms | 5000个100 ns低样点；策略参数，不是通用标准 |
| UART | 115200 baud、8N1 | 每字节10bit；整数波特率分频的误差要说明 |
| 关联窗口 | V2为1 ms | 10000个100 ns间隔；以统一时间编号作边界比较 |

初学阶段优先“一样点一字节，低4位有效”的上传格式：32768 点负载为 32768 byte=32 KiB，8N1纯传输时间约 `32768×10/115200=2.84秒`。RAM 16 KiB 与串口负载 32 KiB 是不同口径。若改为每字节两样点，负载变16 KiB，必须同步修改格式版本、解析器与时间估算；不要只改一侧。

## 同步与事件

外部输入先在50MHz域两级同步，保留 `ASYNC_REG` 属性，再进入采样路径；两级同步降低亚稳态传播概率，不证明所有短脉冲均可捕获。复位使用异步置位/同步释放等一致方案，模块端口说明有效极性。

`sample_ce` 表示当前系统时钟沿是否处理样点。事件有效脉冲的宽度注明为“一系统时钟周期”或“一采样周期”。若事件寄存器仅在 `sample_ce` 分支更新，一次高电平可能持续5拍；需要一系统拍时，应每拍默认清零，只在样点条件命中时置1。跨模块读取寄存器事件的一拍延迟同样要对齐。

边沿比较同步采样后的“当前值”与“上一个样点值”。边沿、原始样点、样点编号必须使用相同取样约定，避免解析路径和波形相差一个索引。

## 缓存与触发索引

开始编码前确定：触发对应哪个写入样点、触发样点算后触发区还是前触发区、计数从0还是1、最后一笔写入何时完成、冻结何时生效。

可用默认约定：0起始输出索引；完整256点窗中128个点严格在触发前，触发样点位于输出索引128，随后再保留127点。总数为256。正式深度同理；不足前触发历史时缩短有效数据，不伪造未采集样点。已有工程采用其他自洽约定则保留并注明。

教学先用8点小圈讲清地址，再使用256点实验。维护“下一写地址、有效样点数、触发原始编号/物理地址、冻结后读起点、最终输出触发索引”的区别。最终索引由读起点和有效区间换算，不能直接发送物理触发地址。

RAM读请求与数据有效按照实际IP的配置延迟对齐，用简单寄存器传递读有效和对应地址。深度变化时：地址位宽需能表达 `DEPTH-1`；有效计数需能表达 `DEPTH`，常比地址多一位；不要默认一次只改DEPTH就无需重新生成IP。

## UART与电脑帧

先用常量字节验证发送，再连续发送小缓存。发送请求仅在UART可接受时提交；传输进行时保持待发送数据及元数据，不因busy误丢或重复字节。

帧需明确帧头、版本、通道映射、采样周期、样点数、触发索引、原因码、负载字节数、字节序、校验范围和算法。首次可使用解释清楚的简单校验；不宣称简单校验能发现所有错误。接收按长度解析并校验，异常后重新查找帧头，不能把负载内的帧头字节直接当新包。

电脑端先保存原始文件再绘图；时间轴用 `(样点索引-触发索引)×采样周期`。冻结上传期间存在监测空窗，重新布防才进入下一轮。

## I2C与关联规则

SCL高电平期间，SDA下降表示START，上升表示STOP；普通数据在低电平阶段变化，字节按MSB先收，第9个SCL时钟观察应答。判断必须基于足够稳定、同一采样时基的同步信号，覆盖同时边沿等边界。

START后第一字节为7位设备地址加读写位；其后应答属于地址阶段。读事务最后一个数据字节后的主机NACK通常表示读结束，不触发地址NACK规则。repeated START重新进入地址阶段。布防在事务中间或事务截断时标记不完整，不补猜缺失信息。

监听器的SCL/SDA端口是输入，不能有驱动/输出使能，不产生ACK和时钟。合法时钟拉伸可能超过用户策略阈值；地址NACK也可能来自地址不对、设备忙或未连接，不能单凭这些事件断定唯一根因。

V2首次A路指定地址NACK锁存 `t0`；等待期间新A事件不重启；只认可B路指定地址的地址ACK。定义 `tB-t0 <= 窗口` 为成功，恰好截止时ACK优先；没有匹配事件直到截止之后判超时。测试若涉及时间计数器绕回，应约定可支持的窗口和比较方法。关联模式A_NACK只启动等待，不能提前冻结。

## 上板核对

计划链路为NUCLEO-F401RE与3.3V TMP102，独立参考逻辑分析仪用于逐字节对照。实际设备是否拥有、是否接好，以用户说明或检查为准。

接线时核对共地、供电、上拉电压、引脚和板卡版本：FPGA与MCU共地，各板供电输出不直接并联；TMP102与SCL/SDA上拉确认3.3V；不能把升腾Pro部分CN3/CN4的5V供电脚当3.3V。FPGA监听引脚保持输入；缓冲器输出只接FPGA；受控SCL拉低用开漏拉低/释放。UART逻辑电平与RS232电气电平分清，连接遵循实际原理图。

上板与引脚未知不阻止编写可仿真的通用模块；XDC具体引脚未核实时不编造。数字输入只能观察逻辑电平，不能测模拟上升时间、振铃幅度或证明电气合规。
