# 讲解与中文注释示例

以下为讲解模式与自行编写的简短示例，不是课本原代码，也不表示项目已经实现。按当前任务选一种，避免每次重复全部模板。

## 从生活比喻回到电路

可以把寄存器比作只在铃响时抄一次内容的小本子，把计数器比作记录铃响次数，把环形缓存比作有限页数、写满后从第一页继续写的本子。紧接着说明电路中的对应关系：铃响=时钟沿，本子内容=寄存器，页号=地址。不要把比喻延伸到错误的串行程序执行印象。

## 用旧值表解释非阻塞赋值

代码：`q1 <= din; q2 <= q1;`。沿到来时两句都读取旧值，更新后q1是本次din，q2是之前q1。不是先改q1，再让q2拿新q1。

假设复位后q1=q2=0，输入在每个观察沿前稳定：

| 上升沿 | 沿前din | 沿前q1 | 沿后q1 | 沿后q2 |
|---|---:|---:|---:|---:|
| 1 | 1 | 0 | 1 | 0 |
| 2 | 0 | 1 | 0 | 1 |
| 3 | 1 | 0 | 1 | 0 |

将这个表用于两级同步、边沿检测和事件编号解释。真实输入为异步信号时另有亚稳态问题，功能仿真表不能代替硬件同步分析。

## 简单采样使能示例

先解释：50MHz每20ns一拍；数0、1、2、3、4共5拍，末值时允许其他模块取样。整个工程仍用50MHz，不产生新的分频时钟。

```verilog
// 功能：每5个系统时钟允许采样一次，50MHz对应10MSa/s。
// 前提：rst_n已在本时钟域同步释放；所有使用者仍由clk驱动。
module sample_ce_gen (
    input  wire clk,        // 系统时钟，50MHz，上升沿工作
    input  wire rst_n,      // 低有效复位，本例使用同步复位
    output wire sample_ce  // 为1的时钟沿处理一个新样点
);
    // 3位能表示0~7，本模块只用0~4；4以后回到0。
    reg [2:0] div_count;

    // 对当前计数值作组合判断，供下一个到来的时钟沿使用。
    // 加入rst_n，保证复位期间不产生采样许可。
    assign sample_ce = rst_n && (div_count == 3'd4);

    // 时序逻辑使用非阻塞赋值；判断读取的是沿到来前的计数值。
    always @(posedge clk) begin
        if (!rst_n) begin
            div_count <= 3'd0;
        end else if (div_count == 3'd4) begin
            // 0~4一共5次：到4就回零，不能再多等一拍。
            div_count <= 3'd0;
        end else begin
            div_count <= div_count + 3'd1;
        end
    end
endmodule
```

复位释放后的沿前计数依次为0、1、2、3、4，对应采样许可0、0、0、0、1；随后重复。消费模块使用 `always @(posedge clk)` 内的 `if (sample_ce)`，不能用 `always @(posedge sample_ce)`。

这是固定5分频的教学示例。实际任务若要求参数化，就解释计数宽度与除数范围后再参数化；不要为了通用性提前堆复杂函数。若现有模块的sample_ce是寄存器输出，保留其设计，但解释下游在下一时钟沿才读取它以及编号如何对齐。

## 低超时的关键注释

先规定“第N个连续低样点触发”。沿前计数为N-1时，本次低样点是第N个，所以比较N-1。高电平清零计数和已触发标志；持续低电平达到阈值后停止增长或保持饱和，事件只发一次。测试N=1、N-1个低点、N个、N+1个和恢复后再低。

注释应解释：计数单位是样点而非50MHz时钟；为什么比较N-1；为什么默认把事件清零；为什么不让计数器无限增长。采样时间量化与输入同步有延迟，不能把“第N个低样点”写成对模拟边沿的零误差计时。

## 状态图与代码对应

先给每个状态一句话：IDLE等布防，ARMED保存前史，TRIGGERED继续保留后史，FROZEN停止改写，UPLOAD逐字节上传。再在每条箭头标注唯一的条件，说明哪个计数器发出完成事件。

简短实现用清楚的case即可；输出应注明组合还是寄存器输出。非法状态恢复、复位、第一次触发锁存、上传期间不写RAM都要可观察。不要为了“看起来规范”把一项简单行为拆成多层难追踪的逻辑。

## 缓存图的两个顺序

用8点地址圈展示物理地址0—7，另画冻结后从最旧有效点到最新点的时间列表。标出下一写地址、触发所在地址和读起点。

先问图中的“第几个有效样点”，再映射物理地址。例如读起点为6，时间序地址顺序就是6、7、0、1、2、3、4、5；若触发地址是2，输出触发索引为4。未写满时只画真正有效的数据，不画虚构前史。
