# 2026-10-27 上位机更新与验证

本提交包已同步最终工程的上位机故障波形自动跟随修复。RTL、MCU和映像沿用既有版本，Word/PDF报告仍为10月23日的历史稿；本页说明后续PC变化。

## 更新后的行为

- 默认跟随最新一份完整、校验通过的A故障原始波形。旧版本仅固定第一份故障，可能出现顶部已显示地址NACK、波形仍停在此前SCL低超时的情况。
- 双击捕获列表或打开归档后进入手动固定。点击“跟随最新故障”恢复，并立即转到最近完整故障。
- 异常事件先到而对应波形尚未完整上传时，明确提示“最新异常尚无对应完整波形”，暂保留上一份证据。坏CRC、缺块或不完整的捕获不会替换完整证据，也不补零生成假波形。
- B正常原始波形保持独立更新；只更新B时，上方故障图和缩放保持。自动切到一份新故障后重新聚焦本份通信区间。

会话新增`latest_fault`用于界面跟随。原`pinned`仍保存首份故障供历史接口使用，`latest_b`仍保存最新含完整B读取的真实波形。界面会显示当前自动/手动模式与捕获编号。

## 运行与检查

Windows直接双击根目录的[启动上位机.bat](../启动上位机.bat)，由`tools/launch_pc.ps1`自动检查本包环境、首次安装依赖并启动。原`tools/run_pc.ps1`命令行入口保留，安装与环境参数见[README](../README.md)及[使用说明](../上位机使用说明.txt)。已打开的旧上位机需要关闭后重新启动；不需要重新烧录FPGA。

本次在提交包的独立副本运行31项单元测试、既有RTL字节流回放、Tk/鼠标回调、两种尺寸滚动布局和无UI消费者的后台归档检查。使用已验证的RTL仿真流作为输入，本轮没有重新执行RTL仿真、综合、下载或现场串口验收。结果与源码摘要见[PC验证记录](pc_validation_20261027.json)。

其中4项新回归覆盖最新完整故障更新、正常B不覆盖故障、分片/整波形CRC拒收、事件先到的等待提示、手动固定以及跨会话关联号重复。GUI检查覆盖手动固定时视图保留、恢复后立即转到最新故障，以及无完整故障时清除旧图。

原工程另只读回放了10月26日截图对应的现场会话，确认#47/#48的低超时自动切到#51起的地址NACK，最终#82。该现场流原有CRC等传输错误，与修改前解析结果逐项一致，未在本轮定位其来源。原始现场流和逐点样本按精简要求留在本机完整归档，不随本包重复上传。
